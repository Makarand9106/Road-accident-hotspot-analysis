# Results of Preprocessing

This folder contains the consolidated output of the entire STATS19 data preprocessing pipeline.

## What is here

| File | Description |
|---|---|
| `quality_report.json` | Full JSON quality report generated by `python python/preprocessing/run_pipeline.py` |
| `preprocessing_summary.md` | Human-readable summary of all cleaning, deduplication, null-handling, and aggregation steps |
| `accidents_clean.csv` | Cleaned accident/collision records (copy from data/processed/) |
| `vehicles_clean.csv` | Cleaned vehicle records (copy from data/processed/) |
| `casualties_clean.csv` | Cleaned casualty records (copy from data/processed/) |
| `split_summary.md` | Summary of train/val/test split applied for ML modeling |
| `eda_visualizations/` | All EDA plots as PNG files generated by the visualization pipeline |

## How to regenerate

```bash
# 1. Run the full preprocessing pipeline
python python/preprocessing/run_pipeline.py

# 2. Copy outputs here
cp data/processed/quality_report.json preprocessing/results_of_preprocessing/
cp data/processed/accidents_clean.csv preprocessing/results_of_preprocessing/
cp data/processed/vehicles_clean.csv preprocessing/results_of_preprocessing/
cp data/processed/casualties_clean.csv preprocessing/results_of_preprocessing/

# 3. Run EDA visualizations
python python/analysis/run_eda.py
```

## Cleaning Steps Performed

1. **Column Standardization** — All columns normalized to snake_case; collision/accident naming aliases resolved
2. **Duplicate Removal** — `drop_duplicates()` on all rows; then deduplication on primary key (`accident_index`)
3. **Sentinel Unknown Conversion** — Values -1, 9, 99, NULL, NaN, NONE strings converted to `np.nan` per domain rules
4. **Date/Time Parsing** — `accident_date` parsed from DD/MM/YYYY → ISO 8601; `time` standardized to HH:MM
5. **Coordinate Validation** — Lat/Lon checked against UK bounding box (49.85–60.90°N, -8.65–1.80°E); `has_valid_coords` flag added
6. **Orphan Removal** — Vehicle and casualty records without a matching accident index removed
7. **Feature Engineering** — `time_period`, `is_severe`, `involves_motorcycle`, `involves_hgv`, `involves_cyclist`, `day_of_week_name`, BNG easting/northing derived
8. **Reference Label Join** — Numeric codes decoded to human-readable labels via `data/reference/` lookup CSVs

## Aggregations Produced

- Accidents grouped by year, severity, weather condition, road type, time period, day of week, speed limit
- Casualty counts per accident, sex/age distributions
- Vehicle type frequency distributions
- Hourly and day-of-week accident matrices for heatmap generation
