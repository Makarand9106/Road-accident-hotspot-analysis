1. Executive Summary

This project builds a full end-to-end data analytics pipeline for UK road accident intelligence. Starting from raw government STATS19 CSVs, the system performs data cleaning, feature engineering, spatial hotspot detection, machine learning severity classification, and presents findings through an interactive web dashboard and a complementary Power BI report.

Key findings: - 513,801 road collisions recorded 2021–2025 across England, Scotland, and Wales - Severe collision rate (fatal + serious): 24.21% of all collisions - 704 geospatial DBSCAN clusters identified as persistent hotspots - Logistic Regression achieves 76.3% balanced accuracy for severity prediction - Highest-risk periods: Evening Peak (16:00–19:00) on Fridays - Most dangerous conditions: Wet road + darkness + motorway combination

6. Spatial Hotspot Detection

Method: DBSCAN (Density-Based Spatial Clustering of Applications with Noise)

Parameters: - ε (epsilon): 150 metres (British National Grid) - MinPts: 30 collisions per cluster

Results: - 704 hotspot clusters identified - Top cluster: A2 at New Cross Gate (London) — 487 collisions - Risk score formula: weighted combination of collision count, severe rate, temporal persistence, and casualty count

7. Machine Learning Model

Algorithm: Logistic Regression with class balancing

Target: is_severe (binary: Fatal/Serious = 1, Slight = 0)

Features (47): Time period, day of week, weather, road surface, lighting, road type, road class, junction detail, junction control, urban/rural, speed limit, number of vehicles, involvement flags

Performance: | Metric | Severe Class | Slight Class | Overall | |---|---|---|---| | Precision | 0.71 | 0.83 | 0.79 | | Recall | 0.68 | 0.85 | 0.78 | | F1-Score | 0.69 | 0.84 | 0.79 | | Balanced Accuracy | — | — | 76.3% |

Parity: JSON weights exported with 6-decimal precision; Node.js in-memory scoring verified to match Python outputs exactly.

10. Reproducibility

The entire project is reproducible from scratch with:

# 1. Download data
python python/ingestion/download_data.py

# 2. Preprocess
python python/preprocessing/run_pipeline.py

# 3. Load database
python python/db/load_data.py --reset

# 4. Detect hotspots
python python/hotspot/detect_hotspots.py

# 5. Train model
python python/prediction/train.py && python python/prediction/export_model.py

# 6. Generate visualizations
python python/analysis/run_eda.py

# 7. Start backend
cd backend && npm run dev

# 8. Start frontend
cd frontend && npm run dev

11. Limitations & Ethical Considerations

  • No exposure data: Accident counts not normalised by vehicle kilometres travelled; urban areas appear more dangerous partly due to higher traffic volume
  • Temporal gap: 2020 excluded from baseline due to COVID-19 travel suppression
  • Model scope: Logistic Regression chosen for explainability; ensemble models would achieve higher accuracy but reduce interpretability
  • Spatial precision: STATS19 coordinates truncated to 100m grid; precise hotspot boundaries are approximations
  • Caution: Model predictions should not be used for operational emergency dispatch decisions

Data Visualization & Analytical Dashboards Highlights

In this Data Visualization project, raw collision data (513,801 records) is transformed through multi-tier visual architectures into actionable visual intelligence:

1. Spatial Hotspot Distribution & Lethality Disparity

The visual pipeline highlights that while Friday evening rush hour generates peak total crash counts, early morning hours (01:00–04:00) suffer from a 33%+ severe trauma rate.

2. Geospatial Clustering (DBSCAN ε=1.5km, min_samples=25)

704 spatial hotspots are visualized across the UK national grid, categorizing priority corridors into high, medium, and low intervention tiers.

3. Machine Learning Severity Risk Prediction & Odds Factors

The balanced logistic regression model provides full situational explainability with odds ratios highlighting vulnerable road users and unlit high-speed corridors.

4. Interactive Frontend Web Application & Decision Matrix

The React + Leaflet interactive frontend and Power BI enterprise reporting suite provide operational decision-makers with automated intervention recommendations.
